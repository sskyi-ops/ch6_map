# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱

Streamlit과 Folium을 활용하여 부산 지하철 역별 이용객 수를 지도 위에 시각화하고 분석하는 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **데이터 업로드 및 확인**
   - `busan_subway.csv` 파일을 업로드하여 데이터프레임 형태로 확인합니다.
   - 이용객 수가 가장 많은 상위 5개 역을 순위표로 제공합니다.

2. **호선별 필터링**
   - 다중 선택(multiselect) 메뉴를 통해 원하는 호선만 선택하여 지도에 표시할 수 있습니다.

3. **지능형 지도 시각화 (Folium)**
   - **원의 크기**: 이용객 수의 제곱근($\sqrt{\text{이용객수}}$)에 비례하여 원의 면적이 설정됩니다.
   - **호선별 색상 구분**:
     - 🟧 1호선: 주황색 (`orange`)
     - 🟩 2호선: 초록색 (`green`)
     - 🟫 3호선: 갈색 (`brown`)
     - 🟦 4호선: 파란색 (`blue`)
   - **마우스 툴팁 & 팝업**: 
     - 마우스를 올리면 호선과 역명이 표시됩니다.
     - 클릭 시 상세 이용객 수가 팝업으로 나타납니다.

---

## 📁 데이터 형식 (`busan_subway.csv`)

업로드하는 CSV 파일은 아래와 같은 열(Column)을 포함해야 합니다.

| 호선 | 역명 | 위도 | 경도 | 이용객수 |
| :--- | :--- | :--- | :--- | :--- |
| 1호선 | 서면 | 35.1578 | 129.0594 | 85000 |
| 2호선 | 해운대 | 35.1631 | 129.1636 | 42000 |

## 🛠️ 설치 및 실행 방법

### 1. 필수 라이브러리 설치

`requirements.txt` 파일을 이용하여 필요한 라이브러리를 한 번에 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 앱 실행

터미널에서 아래 명령어를 입력하여 Streamlit 앱을 실행합니다.

```bash
streamlit run app.py
```
